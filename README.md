## Описание проекта

Blackjack — графическая карточная игра, в которой пользователь играет
против компьютерного дилера и стремится набрать больше очков, не превышая 21.
Приложение будет разработано на Python с использованием Tkinter и будет
включать анимацию раздачи карт, управление действиями игрока и статистику
раундов.

## Статус проекта

Выполнены первые шесть этапов плана, включая отрисовку стола,
элементы управления и анимацию раздачи.

На столе отображаются карты и очки игрока и дилера. Вторая карта дилера
скрыта во время хода игрока. Кнопки «Новый раунд», «Взять карту» и
«Остановиться» подключены к модели и доступны в соответствующих
состояниях раунда. После завершения показывается результат.

Карты по одной перемещаются из колоды на стол. В начале раунда игрок
и дилер получают карты по очереди. Дилер раскрывает вторую карту и
при необходимости добирает карты с паузой между шагами. Во время
движения карт и хода дилера кнопки заблокированы. Статистика и
дополнительные функции остаются в плане.

## Правила игры

### Цель

Набрать сумму очков, которая больше суммы дилера, но не превышает 21.
Превышение 21 называется перебором и приводит к поражению.

### Значения карт

| Карты | Количество очков |
| --- | --- |
| От 2 до 10 | По номиналу |
| Валет, дама, король | 10 |
| Туз | 11 или 1 — выбирается значение без перебора, если это возможно |

Масть карты на количество очков не влияет.

При подсчёте каждый туз сначала считается за 11. Если сумма превышает 21,
значение одного туза уменьшается на 10. Это повторяется, пока сумма
не станет допустимой или не закончатся тузы, учитываемые за 11.

Например:

- Туз и 7 дают 18 очков.
- Туз, 7 и 9 дают 17 очков.
- Два туза и 9 дают 21 очко.

### Начало раунда

1. Создаётся и перемешивается колода из 52 карт без джокеров.
2. Игроку и дилеру поочерёдно выдаются по две карты.
3. Обе карты игрока открыты.
4. Первая карта дилера открыта, вторая скрыта.
5. Проверяется наличие blackjack у игрока и дилера.

**Blackjack** — это туз и карта стоимостью 10 очков в начальной руке
из двух карт. Сумма 21, набранная тремя и более картами, не считается
blackjack.

Если blackjack есть у обоих участников, объявляется ничья.
Если только у одного — этот участник побеждает, раунд завершается,
а закрытая карта дилера раскрывается.

### Ход игрока

- **«Взять карту»** — получить дополнительную карту.
- **«Остановиться»** — завершить свой ход и передать его дилеру.
- При переборе игрок сразу проигрывает.
- При достижении 21 ход автоматически переходит к дилеру.

Во время раздачи и хода дилера действия игрока блокируются,
чтобы повторные нажатия не нарушали порядок игры.

### Ход дилера

После завершения хода игрока дилер раскрывает вторую карту:

- при сумме меньше 17 берёт карту;
- при сумме 17 или больше останавливается;
- при «мягких 17», например тузе и шестёрке, также останавливается.

Если у игрока уже произошёл перебор, дилер раскрывает карты,
но дополнительные карты не набирает.

### Определение результата

| Условие | Результат |
| --- | --- |
| Игрок набрал больше 21 | Поражение игрока |
| У дилера перебор, у игрока перебора нет | Победа игрока |
| У обоих не больше 21, сумма игрока больше | Победа игрока |
| У обоих не больше 21, сумма дилера больше | Поражение игрока |
| Допустимые суммы равны | Ничья |

### Принятый вариант правил

В проекте используется базовый вариант blackjack без денежных ставок.
Разделение пар, удвоение ставки, страховка и досрочная сдача не реализуются.
Перед каждым раундом создаётся новая перемешанная колода.

## Оформление и анимация

Игровое поле оформлено как карточный стол:

- сверху располагается рука дилера;
- снизу — рука игрока;
- сбоку — колода;
- под игровым полем — кнопки действий и сообщение о ходе или результате.

Карты рисуются средствами Tkinter Canvas: прямоугольники,
обозначения номиналов и мастей. Внешние изображения и платные материалы
не требуются.

Перемещение каждой карты из колоды на стол занимает около 250 мс.
Кадры обновляются через `after()`, поэтому окно реагирует на изменение
размера и закрытие во время раздачи.

## Установка и запуск

### 1. Клонирование репозитория

Замените `<URL_РЕПОЗИТОРИЯ>` адресом публичного репозитория проекта:

```bash
git clone <URL_РЕПОЗИТОРИЯ> blackjack
cd blackjack
```

Также можно скачать ZIP репозитория, распаковать его и открыть терминал
в корневой папке проекта.

### 2. Создание и активация виртуального окружения

**Windows, командная строка cmd:**

```bat
python -m venv venv
venv\Scripts\activate.bat
```

**Windows, PowerShell:**

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
```

Если PowerShell запрещает запуск скрипта активации, используйте cmd.

**macOS / Linux:**

```bash
python3 -m venv venv
source venv/bin/activate
```

Окружение необходимо создавать для своего компьютера.
Если в полученной копии проекта уже есть чужая папка `venv`,
её следует заменить собственным окружением.

### 3. Проверка Tkinter

В активированном окружении выполните:

```bash
python -m tkinter
```

Должно открыться тестовое окно Tcl/Tk. После проверки закройте его.

Если модуль отсутствует, установите сборку Python с поддержкой Tkinter.
Для Ubuntu/Debian можно установить системный пакет:

```bash
sudo apt install python3-tk
```

Tkinter не устанавливается через `pip`.

### 4. Установка зависимостей

```bash
python -m pip install -r requirements.txt
```

В `requirements.txt` указана необходимая версия Python. Сторонние пакеты
для запуска приложения не требуются.

### 5. Запуск программы

Из корневой папки проекта:

```bash
python main.py
```

Откроется игровой стол. Нажмите «Новый раунд», чтобы начать игру.

### Обоснование структуры

Математическая и игровая логика отделена от интерфейса.
Это позволяет проверять подсчёт очков и определение победителя
без запуска Tkinter.

Отрисовка вынесена в отдельный класс, чтобы изменения оформления
не затрагивали правила игры. Класс `App` связывает модель,
элементы управления и анимацию.

Модель выполняет начальную раздачу в `start_round()` и хранит состояние
раунда: ожидание, ход игрока, ход дилера или завершение. Действия вне
своего хода не меняют состояние. Метод `dealer_step()` выдаёт не более
одной карты за вызов, чтобы интерфейс мог анимировать каждую выдачу.

## Пример использования

Ниже приведён пример возможного раунда. Конкретные карты случайны.

1. Пользователь запускает программу и нажимает «Новый раунд».
2. Игрок получает 10 и 6: на экране отображается сумма 16.
3. У дилера открыта 9, вторая карта скрыта.
4. Игрок нажимает «Взять карту» и получает 4: сумма становится равной 20.
5. Игрок нажимает «Остановиться».
6. Дилер раскрывает вторую карту — 8. Его сумма равна 17,
   поэтому он больше не берёт карты.
7. Приложение сообщает о победе игрока и обновляет статистику.
8. Пользователь начинает следующий раунд.

## Проверка качества

Тесты карт, колоды, руки и правил раунда запускаются из корня проекта:

```bash
python -m unittest discover -s tests -v
```

### Реализованные автоматические проверки

- Номиналы всех мастей имеют правильную стоимость; карты неизменяемы.
- Колода содержит 52 уникальные карты.
- Выданная карта удаляется из колоды.
- Пустая колода вызывает `IndexError`; перемешивание не возвращает карты.
- Очки правильно подсчитываются для одного и нескольких тузов.
- Blackjack отличается от суммы 21, набранной несколькими картами.
- Перебор определяется после уменьшения стоимости тузов.
- Очистка руки сбрасывает очки и признаки blackjack и перебора.

### Автоматические проверки правил раунда

- Проверяется blackjack у обоих участников.
- Вторая карта дилера скрыта до завершения хода игрока.
- Перебор игрока немедленно завершает раунд.
- При достижении 21 ход переходит к дилеру.
- Дилер берёт по одной карте за шаг при сумме меньше 17.
- Дилер останавливается на обычных и мягких 17.
- Победа, поражение и ничья определяются корректно.
- Недопустимые действия не изменяют состояние игры.
- Новый раунд создаёт новую колоду и сбрасывает результат.

### План ручных проверок

- Плавность раздачи и последовательность появления карт.
- Скрытие второй карты дилера до её раскрытия.
- Отсутствие повторной выдачи карт при быстрых нажатиях.
- Работа кнопок и горячих клавиш.
- Начало нового раунда и сброс статистики.
- Закрытие окна во время анимации без ошибок.
